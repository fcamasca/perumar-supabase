## Criterio de evaluación y registro

Registrar por caso: estado real, pasos/dataset sintético, actor/rol, entorno, evidencia, limitación y riesgo residual. Para PDF: número de páginas, recortes/solapamientos, texto íntegro y capturas; para seguridad: HTTP/rol/operación sin incluir secretos ni documento personal en logs. Para desempeño: muestras frías/calientes y percentiles, CPU y memoria si son observables, tamaño, costo con supuestos y tiempo de mantenimiento. No presentar una prueba local como hospedada ni una aprobación global como subcasos humanos ejecutados.

Requisitos críticos de contenido/seguridad no satisfechos no se compensan por un PDF visualmente bonito. Si se necesita otro backend o expansión de arquitectura, se detiene la expansión y se informa el resultado. Una limitación importante o prueba esencial no disponible impide declarar suficiencia sin reservas y debe quedar visible en GATE-A01. Ningún test concede aprobación humana de gates automáticamente.
